# VR4ALL v0.3.44 beta

Adds **BioShock VR** to the standalone Quest catalog. Its card accepts an installed copy of the original BioShock 2007 v1.1 PC game and runs [terx1232's official Quest installer](https://github.com/terx1232/BioShock-Quest-VR/releases/tag/initial-release) for the selected Quest 3 or Quest 3S. VR4ALL checks the installer download against GitHub's SHA-256 digest and checks the creator's installation receipt afterward. The new card uses a screenshot from the creator's release.

BioShock VR is experimental. Its creator has not yet confirmed gameplay on Quest 3/3S hardware. It needs roughly 7 GB of free PC space and 14 GB of headset space. It uses the Android package ID `com.winlator.cmod`, which can conflict with another app using that ID. VR4ALL has tested the input checks and install orchestration with automated fixtures, but this release has **not** been installed and played on a physical headset through VR4ALL.

The catalog now contains **95 game cards and 101 port choices**. Existing game workflows remain unchanged.
