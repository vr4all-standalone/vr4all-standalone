# VR4ALL v0.3.93 beta

- Fixed **Newest** sorting. It now uses when each port was added to VR4ALL, rather than its position in one of the catalog source files.

- Added a catalog check so future ports must include an addition date.

**Updated recently** remains based on creator release dates.
