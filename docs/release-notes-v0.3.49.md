# VR4ALL v0.3.49 beta

Adds 15 standalone Quest game cards: Ghost Squad Evolution, The House of the Dead 4, Daytona USA, Mario Party 4, Crash Team Racing, Iron Lung, Victory Heat Rally, Mystical Ninja, WWF No Mercy, Sin and Punishment, NFL Blitz 2000, Bomberman Hero, Arx Libertatis, Jurassic Park Arcade, and WakerQuest. The catalog now has 114 game cards and 121 port choices.

Ghost Squad Evolution and The House of the Dead 4 use separate Quest APKs from the same Lindbergh release. Daytona USA selects only Daytona assets from Port0r's shared repository. The new N64 and GameCube cards describe the original game files and first-run picker requirements. Wind Waker's PAL Rev 0 ISO and Mario Party 4's game ID receive disc-header checks.

Victory Heat Rally now builds in VR4ALL from the creator's release ZIP and the player's owned `data.win`, then installs the resulting personal APK to the selected Quest. First builds download the creator's tool dependencies. Iron Lung requires a creator APK downloaded manually from itch.io. Jurassic Park Arcade has no redistributable APK and remains an official source-build guide card; VR4ALL cannot yet complete that build from a single game-file drop.

All 15 cards have local game or creator artwork. Source URLs and file destinations were audited against creator documentation and current releases. Automated checks are separate from a physical headset install and play test; these new ports have not been played on a headset as part of this release.
