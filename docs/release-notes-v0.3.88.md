# VR4ALL v0.3.88 beta

- Added **Birdman64VR**, Corrie Divitt's native Quest 3 VR port of Pilotwings 64, with the creator's official artwork and direct Quest APK updates.
- Bring your own US Pilotwings 64 ROM in `.z64`, `.n64` or `.v64` format, or a ZIP, 7z or RAR containing one. VR4ALL checks the creator's exact ROM SHA-1 across N64 byte orders, installs the Quest APK, and copies the ROM to the port's documented headset folder.
- The port builds the game on the Quest the first time it starts and needs internet for that one-time step. The creator has tested Quest 3; other Quest models remain unverified.

VR4ALL now lists 165 game cards, 7 emulator/runtime cards and 184 port choices. The Birdman64VR integration has automated catalog, ROM, install-plan and headset-scan tests. A physical headset install and gameplay check have not yet been performed for this new card.
