# VR4ALL v0.3.57 beta

Adds four standalone Quest game cards: Daggerfall Unity VR, Star Fox Enhanced VR, QuestCraft, and Outlaws VR. Each points to the creator's source. Outlaws VR and Star Fox Enhanced VR use the Quest APK inside the creator's release ZIP. Outlaws VR also transfers the required LAB and KPF files from an owned copy of Outlaws Remastered. Its optional movie and music conversion remains in the creator's installer and is not automated in VR4ALL.

Adds an **Emulators** library view with AGE of Joy, CitraVR, DolphinXR, PPSSPP VR, and WinlatorXR. AGE of Joy is an arcade gallery and WinlatorXR is a Windows compatibility runtime; neither includes commercial games. The four GitHub projects with verified Quest APK releases can be downloaded in VR4ALL. PPSSPP VR uses a manual APK from the [official download page](https://www.ppsspp.org/download/) because its Quest APK is not published in the project's GitHub release feed.

The library dropdown now starts with **All games**, **New games**, **Emulators**, and **Ready to install**. The app version appears by the VR4ALL logo at the top left. The catalog now contains **128 game projects, 5 emulator and runtime cards, and 141 port choices**.

Release selection, APK extraction, catalog, and interface tests passed. These new ports have not been physically installed or played on a Quest during this release check. Use owned game files where the card requests them.
