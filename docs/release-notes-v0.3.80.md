# VR4ALL v0.3.80 beta

- Added Bugdom VR and Bugdom 2 VR as separate Quest cards. Both use the creators' GitHub beta APKs and include their free game data, so no ROM or PC build is needed.
- Both cards use creator screenshots. Headset scans recognize each game's Android package and can check for future creator APK releases.

The creator reports Quest 3 testing for both ports. VR4ALL's install flow was tested in software; these new installs were not played on a physical headset for this release.
