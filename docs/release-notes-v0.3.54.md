# VR4ALL v0.3.54 beta

Adds Max Payne VR: Nightmare Edition to the catalog as a manual creator download. Open the linked Google Drive page for the Quest APK, then select it as a local APK in VR4ALL. Bring the APK and matching OBB from your own Max Payne Mobile 1.7 installation; VR4ALL checks the mobile package and OBB filename before copying them to the Quest. The port imports the game data on first launch.

The catalog now has 119 game cards and 126 port choices. This creator download has no verified automatic update feed, so VR4ALL cannot detect newer Max Payne builds. The Max Payne installation and gameplay have not yet been tested on a headset; the catalog, file checks, transfer plan and scan logic have automated coverage.
