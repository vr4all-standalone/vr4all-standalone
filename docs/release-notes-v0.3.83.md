# VR4ALL v0.3.83 beta

## New Quest port

- Added **WarioWare: Twisted! VR** from [mrchrisster](https://github.com/mrchrisster/WarioWareTwistedRecomp). VR4ALL downloads the creator's Quest APK, verifies your own 16 MiB USA `.gba` ROM against the creator's published SHA-1, and copies it to the headset's documented import path. The Quest build does not need a GBA BIOS.
- Added the creator's Quest banner, headset package detection, and a Game Boy Advance library category.

The port is intended for Quest 3 and 3S. The VR4ALL workflow has been checked in code and tests; headset gameplay for this new card has not yet been verified by VR4ALL.
