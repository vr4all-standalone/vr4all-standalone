# VR4ALL v0.3.91 beta

- Added **Vib-Ribbon VR** from [CorrieDivitt’s official Quest release](https://github.com/CorrieDivitt/Ultimate-Vib-Ribbon/releases/tag/v1.0.0). VR4ALL selects the standalone Quest ZIP, extracts its APK, and installs it with your own PAL Vib-Ribbon CUE and BIN tracks. It performs the creator’s first-launch folder setup and file-permission step before you play.
- The catalog now has 168 game cards, 7 emulator and runtime cards, and 187 port choices.

The creator reports Quest 3 support. Other Quest models and this VR4ALL install path have not been play-tested on a physical headset.
