# VR4ALL v0.3.84 beta

## New Quest port

- Added **Skate 3 AR** from [andrewnakas](https://github.com/andrewnakas/skate3-quest-ar). VR4ALL downloads and installs the creator’s standalone Quest 3 alpha APK. Its clean-room miniature skater works without a Skate 3 disc or file upload.
- Added the creator’s artwork, Xbox/Sports catalog filters, and installed-app detection.
- Owners who have prepared the creator’s optional `Skate3-Quest.zip` on a PC can drop it into the same card; VR4ALL copies it to the documented Quest location. The creator’s retail conversion requires running a separate PC engine to decode sound banks and cannot be completed from the disc by VR4ALL alone. Import the transferred ZIP from the app’s Skate 3 data menu.

The card’s source and transfer paths were checked against the creator’s release and import instructions. Actual Quest gameplay and optional retail import have not been verified by VR4ALL.
