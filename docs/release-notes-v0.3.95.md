# VR4ALL v0.3.95 beta

- Added **Silent Hill 3 Quest VR** from [moistman42069/SilentHill3-Quest-VR](https://github.com/moistman42069/SilentHill3-Quest-VR). VR4ALL downloads the creator's Quest APK and transfers your own 2003 PC game files to the documented headset folder. The card accepts a complete installed folder or ZIP, 7z, or RAR archive and checks the creator's 79 required data files before enabling install.
- VR4ALL checks the transferred game files' sizes on the headset before reporting installation success. The headset library marks Silent Hill 3 ready only when its APK and required files are both present. Its updates can install a newer APK while keeping the transferred game data.
- The card uses the creator's Silent Hill 3 logo on a VR4ALL-made backdrop. The catalog now has 170 game projects, 7 emulator tools, and 189 port choices.

The new route is checked with automated input, release-selection, and headset-state tests. Full game transfer and gameplay still need a test with an owned PC copy and a connected Quest.
