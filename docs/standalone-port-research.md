# Standalone Quest VR game ports: expansion research

## Recent checks (23 October 2026)

- [18 Wheeler: American Pro Trucker VR](https://github.com/f1nal-b0ss/18-wheeler-decomp/releases/tag/v0.1.0) has an official `18wheeler-vr.apk` for Quest 2, Pro, 3 and 3S. Its creator requires an owned USA Dreamcast CHD or GDI/BIN disc set. Added to the installable catalog.
- [OutRun 2006 VR](https://virtuavrport.itch.io/outrun-2006-vr) is described by its creator as a **PC VR work in progress** with **no public build available yet**. Keep it as a future research lead; it cannot currently be installed as a standalone Quest port.

Researched **21 October 2026** for `vr4all`. This is a candidate list, not a statement that each build has been run on a Quest 3 or 3S. “Verified APK” means the port author explicitly publishes a Quest/Android build or an exact Quest APK on an official release page; it does not mean hardware tested here. Release pages can change after this date. Each proposed install must still fetch only from the linked author or author-designated distribution, check the APK architecture, package ID, and content instructions, and avoid redistributing game assets.

## Scope and triage

I compared the 28 profiles present before this expansion in [`src/catalog.js`](../src/catalog.js) and the expansion leads in [`PORTS.md`](../PORTS.md). The catalog now includes several of the recommendations below, including manual discovery profiles. This report does **not** propose duplicate profiles for Lambda1VR, QuakeQuest, Quake2Quest, RTCWQuest, Nintendo 64 Zelda/Mario ports, Halo CE Quest, or the other original games. Doom3Quest, Quake3Quest, JKXR, QuestZDoom, PreyVR and RazeXR were only leads in `PORTS.md`, so they remain eligible for profiles. The [SideQuest Game Ports collection](https://sidequestvr.com/apps/category/gameport) and [awesome-flat2vr](https://github.com/jrejaud/awesome-flat2vr) helped discovery, but both mix workflows and platforms; the author sources below establish standalone status.

Confidence key: **A** = author specifies an exact Quest APK asset or direct official Quest APK; **B** = author/official SideQuest distributes a Quest build, but the exact current Quest asset could not be resolved from the accessible release listing; **C** = proof of a working Quest workflow is incomplete or the build is unsuitable for one-click installation. Complexity is **low** (select a ROM/in-app import), **medium** (copy original game data or use a companion app), or **high** (conversion, multiple APKs, special patching, or large data preparation).

The connected Quest audit also found game data for Wipeout in its imported `wipeout` folder, Road Rash as `disc.bin`, Perfect Dark in app-local `data`, and Vice City in `gamedata`. These locations are now read by the device scan. The installed Crazy Taxi patch and F-Zero X source build are shown as **On headset** without claiming a comparable official APK release. House of the Dead VR remains incomplete in the scan because `hotd.zip` was not found.

1. Use one catalog profile per distinct Quest **package/launcher**, not one per underlying game when the APK is shared (SourceVR, JK XR, QuestZDoom, RazeXR). For Unreal Tournament, PortRoyale and GHWST have distinct packages and installation flows, so two entries can be justified if named clearly.
2. SourceVR's Core/full variants replace the same package. ROM-dependent releases may contain multiple regional or flat Android assets. Resolve the APK from the release's asset manifest and validate name/architecture before showing Install; a release page link is safer than fabricating a direct binary URL.
3. All links above are first-party developer repositories, author websites, or creator-controlled SideQuest/itch listings. The SideQuest category and awesome-flat2vr were discovery sources only. No unofficial APK mirror is proposed.
4. GitHub's rendered release pages sometimes hid asset lists from the research tool. Where an exact name is absent, that is an explicit open item, not an implicit `*.apk` guess. Some 2026 releases are beta/pre-release; title-specific limitations are listed above.
5. There was no physical Quest 3/3S install/play validation in this research pass. Practical validation should check package ID, min Android version, installer behavior, data import, first-level startup, controls and 3S performance. Doom3Quest 1.4.8 deserves priority testing because the official listing says it fixes a crash and recent user reports describe previous startup failures.

## Suggested order

1. **Low-friction verified downloads:** GoldenEye VR, AvP VR, XrKart 64, Unreal Gold VR, either/both Unreal Tournament variants, Mega Man 64 VR.
2. **High-interest guided imports:** SourceVR, GalaxyQuest, native PrimedGun 2.0, Perfect Dark VR, Simpsons Hit & Run VR.
3. **Established SideQuest additions:** Doom3Quest, PreyVR, JK XR, CSVR, Beef Raider XR, Quake3Quest, QuestZDoom, RazeXR. They need SideQuest launch/open actions or exact asset resolution and several need multiple apps or data folders.
4. **Personal builds and patches:** Vice City VR requires a local source build; Crazy Taxi VR requires a personal binary patch. VR4All now guides both from one owned game input. Neither author supplies a complete APK.
