# VR4ALL v0.3.53 beta

Adds two standalone Quest ports to the catalog:

- **Project 06 VR**: installs the creator's Quest APK. The current experimental build packages the playable Sonic content and needs no separate game file upload.
- **Qualyx**: installs the creator's Quest APK and copies the `hlvr` and `core` folders from your own Half-Life: Alyx Steam installation to `/sdcard/Qualyx/game/`. VR4ALL checks for both main VPK files before marking it ready. This transfer needs substantial free space and time.

The catalog now has **118 game cards and 125 port choices**. Creator APK updates remain subject to your approval before installation. VR4ALL has not physically installed or launched these two ports on a headset in this release check.
