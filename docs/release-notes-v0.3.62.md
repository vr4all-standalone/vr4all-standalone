# VR4ALL v0.3.62 beta

GTA: San Andreas and Red Dead Redemption personal builds now show the creator's underlying error in the failed install message when a later PowerShell wrapper reports only the failed command. Python exceptions are also surfaced when available. The build activity is also saved in VR4ALL's install log.

This changes error reporting only; it does not alter game files, build inputs, or headset installation behavior.
