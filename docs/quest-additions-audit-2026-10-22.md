# VR4All: proposed additions from the 30-title shortlist

Checked 22 October 2026 against the original 68-profile catalog and the linked project or author release pages. The implementation has 22 new game cards, four grouped alternate port profiles, and 88 visible game cards / 92 port profiles. The proposal table below records the original research decisions; current implementation and test status are in [the integrated installer notes](integrated-installers-2026-10-22.md).

**Recommendation:** add **22 distinct catalog profiles** from this shortlist, including one combined Descent 1 & 2 profile and one Morrowind profile. Seven alternate ports duplicate an original game already in VR4All; the eighth overlap is the second Morrowind implementation. A proposed profile is not a claim that VR4All can automatically install it yet. Each profile should expose only the install and update actions that its verified release actually supports.

## Catalog implementation gates after approval

1. For every proposed card, inspect the actual release archive/APK for package ID, version code, Android architecture, asset filenames, and signing continuity. A release page alone cannot prove that an update will install over the old APK.
2. Validate the exact owned-file inputs, extraction/conversion rules, destination, and post-install detection. Save a local copy of user-supplied files in VR4All's configurable library before transfer, as the app already promises.
3. Show **Latest on GitHub** only when a verified Quest APK can be selected. For installer ZIPs, creator-hosted itch.io assets, and SideQuest-only downloads, use a truthful source/guide state until the download and update path is implemented.
4. Run a clean install and an update test on a connected compatible headset for each workflow before marking it automatic or “ready.” Source review cannot establish that all 22 play correctly on Quest 2, 3, 3S, and Pro.

The shortlist is limited to the 30 entries the user supplied; it does not replace the broader [143-entry audit](claude-143-quest-audit.md).
