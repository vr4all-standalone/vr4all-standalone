# VR4ALL v0.3.67 beta

Adds two standalone Quest game cards, bringing the catalog to 130 game cards, 5 emulator and runtime cards, and 147 port choices:

- **Ratchet & Clank Quest VR:** installs the creator's Quest APK and transfers an owned PAL SCES-50916 v2.00 or NTSC-U SCUS-97199 v1.00 PS2 ISO. Select the transferred ISO in the headset launcher for its first-run preparation. The creator recommends Quest 3 or 3S and labels this an experimental build.
- **Resident Evil Code: Veronica X VR:** installs the creator's Quest APK and transfers an owned NTSC-U SLUS-20184 PS2 ISO. Allow file access and select the ISO in the headset launcher. This is separate from the existing Survivor 2 arcade port. The creator has tested Quest 2 and lists Quest 3/3S as supported but untested.

Both cards track the original creators' GitHub APK releases. Game discs are not included. Automated checks cover the catalog, APK selection, install plans and headset file detection; neither game was installed or played on a headset for this release check.
