# VR4ALL v0.3.45 beta

Adds **CarnEvil VR** to the standalone Quest catalog. VR4ALL downloads the [creator's official Quest APK](https://github.com/vr4all-standalone/carnevil-vr/releases/tag/v0.1.0), accepts the player's owned CarnEvil v1.0.3 ROM ZIP and matching CHD, grants the app game-file access, and transfers both files to the paths used by the port. It detects whether the APK and both game files are present on the selected headset. Its card uses the port project's CarnEvil banner.

The port's creator confirmed core gameplay, audio, aiming, depth and two-player joining on Quest 3S. Complete route coverage and comfort remain untested. VR4ALL's catalog, release selection, install plan and headset file checks have automated coverage; this integration has not yet been installed end to end through VR4ALL on a physical headset.

The catalog now contains **96 game cards and 102 port choices**. No game data or BIOS is bundled.
