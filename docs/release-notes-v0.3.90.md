# VR4ALL v0.3.90 beta

- Added **Rage Racer VR** from [Thoreman's official Quest release](https://github.com/Thoreman/rage-racer-pc/releases/tag/v0.6.0-beta). VR4ALL selects the Quest APK and installs it with either a CHD or a complete CUE/BIN folder from your own PlayStation disc. It transfers the disc into the app's documented headset folder and checks for it when scanning installed ports.
- The catalog now has 167 game cards, 7 emulator and runtime cards, and 186 port choices.

The Rage Racer profile and install plans passed automated tests. The creator reports testing on Quest 3; we have not play-tested this VR4ALL install on a physical headset. The linked COD4 archive was not added: its page credits an unnamed team and its download does not provide a verifiable creator release or Quest APK identity for safe in-app installation.
