# VR4ALL v0.3.48 beta

Adds GT3 Revisited for Quest with the creator's matching Quest APK. Provide an ISO made from your own Gran Turismo 3: A-Spec disc; VR4ALL transfers it to the headset's Download folder. Select the disc once when opening the game. The author verified Quest 3; other Quest models remain untested.

Virtua Cop now has one game card with two developer ports. VR4ALL's Virtua Cop VR is selected by default, and Port0r's Cop VR remains available within the card. The card now uses the VR4ALL Virtua Cop project banner.

The catalog contains 99 game cards and 106 port choices. All 11 VR4ALL lightgun mods with public Quest releases remain in the catalog. Automated install-plan, headset-scan, and interface checks do not replace a headset install and play test.
