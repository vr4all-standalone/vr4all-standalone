# Integrated Quest install workflows — 22 October 2026

VR4All saves each selected owned game input and local creator APK in its managed library before an install. The right panel docks beside two card columns by default; Settings offers slide-over and focused views. A creator-hosted APK without a verified GitHub asset has a manual download link and local drop area, not a disabled GitHub button.

| Workflow | User supplies | VR4All performs | Remaining user step |
| --- | --- | --- | --- |
| Descent 1 & 2 | Owned installed Descent folder | Downloads the [official Quest ZIP](https://github.com/GameOrDie007/Descent-1-and-2-VR/releases), runs its quiet installer for the selected Quest, preserves existing pilots and saves | Launch to confirm play |
| Gothic II | Owned Gothic II Gold / Night of the Raven folder | Runs the [author's packaged converter and installer](https://github.com/dubrovskiy-yevhen-stakelogic/gothic2-vr/releases) | Choose the prepared ZIP in the headset import screen |
| GT2 | Owned BIN, ISO, or a ZIP containing a CUE/BIN set | Runs the [author's precompiled Quest disc converter and installer](https://github.com/dubrovskiy-yevhen-stakelogic/gt-2-pc/releases); a bare CUE is rejected so its referenced BIN is not lost | Launch to confirm play |
| Animal Crossing | Owned USA Rev 0 GameCube ISO, GCM, or CISO | Runs the [author's Quest ZIP installer](https://github.com/LiquidAzir/animal-crossing-vr/releases), which validates and privately transfers the disc; on Quest 3S, VR4ALL adjusts only the temporary script's model check | Connect one Quest 3 or 3S; the creator has playtested Quest 3 only, so 3S gameplay remains unverified |
| Magic Carpet | Installed owned game folder | Runs the [official Windows importer](https://github.com/NathanaelA/mgcarpet-vr), bakes and copies game data, installs the Quest APK | Launch to confirm play |
| GalaxyQuest | Owned Wii disc image | Runs the [official Windows converter](https://github.com/bigmak94/GalaxyQuest/blob/main/docs/DESKTOP_INSTALLER.md), installs its APK, copies converted data | Allow roughly 16 GB temporary PC space and 7 GB on Quest |
| AstroQuest | Extracted, decrypted European CUSA12392 game folder | Installs the [official Quest 3 APK](https://github.com/bigmak94/AstroQuest) and transfers the validated game tree | A raw disc image or encrypted store package cannot be used |
| Sclerosis | [Creator-hosted APK](https://createam.itch.io/sclerosis-an-amnesia-vr-remake) once, plus owned installed Amnesia folder | Saves the APK, checks `config`, `maps`, and `entities`, installs and transfers the folder | Download a newer creator APK manually for updates |
| QuestZDoom, RazeXR | Optional owned WAD or Duke GRP | Installs the official [QuestZDoom](https://github.com/Team-Beef-Studios/QuestZDoom/releases) or [RazeXR](https://github.com/Team-Beef-Studios/RazeXR/releases) engine and launcher APK pair | Choose the game in the launcher |
| Tiberian Dawn MR | Owned GDI and Nod disc ISOs | Installs the [Quest 3/3S Spatial APK](https://github.com/Cesarus85/Tiberian-Dawn-for-Android-and-Meta-Quest/releases) and copies both discs | Select both ISOs in the author's in-headset importer |

Current official GitHub metadata was checked for the engine, installer ZIP, companion launcher, and converter assets. Four packaged installer ZIPs were extracted locally and their expected scripts and Quest APKs found; the APK package IDs were inspected. Magic Carpet, GalaxyQuest, and AstroQuest transfers write a completion marker only after the data copy succeeds; a partially copied folder stays incomplete. APK-only updates use current headset data readiness, not saved install history, and skip unused Windows tool downloads. Automated tests cover selected-headset targeting, conversion/transfer orchestration, update-only paths, and readiness probes. The headset was disconnected during this pass, and the owned games were unavailable. A completed ADB transfer must still be followed by launching each port to confirm it plays.
