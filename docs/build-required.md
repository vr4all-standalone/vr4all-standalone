# Build or patch required

VR4All can install a prebuilt Quest APK and transfer owned game data when the author publishes an APK and documents the destination. A source project or patch recipe needs a separate, verified preparation process. One ROM alone is not sufficient for every port.

| Port | Owned input | Author process | VR4All status |
| --- | --- | --- | --- |
| [Vice City VR](https://github.com/dubrovskiy-yevhen-stakelogic/vice-city-vr-quest) | Complete owned Vice City PC installation folder or ZIP | Official build-and-install script assembles a personal Quest APK and transfers data | VR4All downloads a commit-pinned official source kit, runs the script for the selected Quest, and remembers the selected game-file path. Initial Android SDK license acceptance or an incompatible installed signing key can still require user action. Full play has not been tested with original files. |
| [Crazy Taxi VR](https://github.com/Baywilly/Crazy-Taxi-VR-Standalone) | Exact compatible original Android `.apkm` package | Apply the author's published `crazywilly.xdelta` patch, then install the resulting APK. The author recommends [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher), a GUI tool. | VR4All downloads the official patch and uses the compatible xdelta3 command-line decoder for unattended patching, validates the resulting APK, then installs it. Full play has not been tested with the owned package. |
| [GTA: San Andreas VR](https://github.com/dubrovskiy-yevhen-stakelogic/gta-sa-vr-quest) | Complete supported Google Play ARM64 base and split APK export, plus the author's exact supported audio pack | Rebuild and sign a personal APK, then install | VR4All runs the official noninteractive builder when both inputs are selected; full build awaits a real owned export |
| [Red Dead Redemption VR](https://github.com/dubrovskiy-yevhen-stakelogic/rdr1-quest) | Complete supported Android package export with base APK, splits, asset packs and external data | Author update wizard rebuilds and installs | VR4All runs the official noninteractive builder from a complete export; full build awaits a real owned export |

## Prebuilt APK or kit, special setup still needed

| Port | Remaining setup step |
| --- | --- |
| [Road Rash Jailbreak VR](https://github.com/dubrovskiy-yevhen-stakelogic/road-rash-jailbreak) | VR4All now runs the official ZIP installer with an owned USA PS1 disc and the selected Quest. End-to-end play still needs an original disc test. |
| [Harry Potter VR](https://github.com/dubrovskiy-yevhen-stakelogic/harry-potter-vr/blob/main/tools/release/PLAYER-INSTALL.md) | VR4All now runs the official player ZIP installer with an owned US PC game folder or ZIP and the selected Quest 3. End-to-end play still needs original game data. |
| [F-Zero X VR (Virtua VR Port)](https://virtuavrport.itch.io/f-zero-x-vr) | Download **Standalone Quest — Install using Windows PC (R10)** from the creator's page. VR4All accepts the complete R10 ZIP or extracted folder and an exact owned US Rev 0 .z64 ROM. It checks both, runs the included Windows extractor, installs the Quest APK, and transfers the prepared data. The creator package needs a manual download once. Headset graphics remain unverified until an on-device test. |
| [Beef Raider XR](https://sidequestvr.com/app/38086/beef-raider-xr-tomb-raider-in-vr) | VR4All downloads and installs the official Quest demo APK. For the full game, run the [author's extraction tool](https://github.com/DrBeef/BeefRaiderXR/releases/download/1.0.0/BeefRaiderXR-1.0.0.7z) on owned Tomb Raider files, launch the headset app once and grant permissions, then drop the extracted `mod` folder into VR4All for transfer. The extractor is a GUI with no verified unattended interface. |
| [JKXR](https://github.com/Team-Beef-Studios/JKXR) | VR4All downloads and installs the official engine and companion APKs, then copies the owned Jedi Outcast or Jedi Academy PK3 files. Choose which game in its card. Grant any requested in-headset permissions. Full play still needs an original game-data test. |
| [The Force Engine VR](https://github.com/SoVRHere/TheForceEngineVR/releases/tag/v0.9.57-quest) | VR4All downloads the Quest APK and copies an owned Dark Forces folder containing `DARK.GOB` into `/sdcard/Android/data/com.tfe.game/files/TheForceEngine/Dark Forces/`, the path identified by the tagged Android source. End-to-end launch awaits a connected Quest and original game data. |
| [Descent 3 VR](https://github.com/SgtBilko76/Descent3-VR/blob/quest-vr-port/quest/README.md) | VR4All downloads the official Quest APK, copies an owned installed PC game folder into the Quest app directory, and sets directory access. Full play still needs an original game-data test. |

These are not source-build projects. Road Rash and Harry Potter use their official installer ZIPs through VR4All. JKXR and Descent 3 use their official Quest APKs and VR4All transfers owned game files. Beef Raider's APK and extracted-data transfer are in VR4All; its author's GUI extractor remains a separate step. Force Engine still links to author instructions while its game-data placement is verified. An installer ZIP is not a directly installable Quest APK.
