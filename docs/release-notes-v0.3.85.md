# VR4ALL v0.3.85 beta

- Add Silent Hill VR for Quest 3, using the creator’s official v0.1 Quest APK from GitHub.
- Accept an owned Silent Hill (USA, SLUS-00707) BIN/CUE folder or archive and transfer the two required disc files to `/sdcard/SilentHillVR/gamedata/`.
- Offer optional HD texture ZIP and HD maps folder fields at the creator’s documented paths.
- Detect the installed `com.sh1vr.quest` app and verify that both disc files are on the selected headset before marking the port ready.

This creator build is an early work in progress. Quest 3 is documented; other Quest models and actual play through VR4ALL have not yet been verified.
