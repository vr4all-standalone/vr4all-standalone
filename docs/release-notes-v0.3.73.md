# VR4ALL v0.3.73 beta

This update adds nine creator-backed standalone Quest projects: Fate of the Galaxy VR, Wing Commander Saga VR, Wipeout Pure VR, Atari Star Wars Arcade VR, SuperTuxKart VR, OpenMW VR Quest, ANKH VR, Visual Pinball VR and ARMSX2 3D. The catalog now has 150 game cards, 7 emulator and runtime cards, and 170 port choices.

VR4ALL selects each creator's Quest APK from their GitHub releases. It copies owned data to the documented Quest paths for Wipeout Pure, Star Wars Arcade, Morrowind and Ultima IV. Fate of the Galaxy and Wing Commander Saga download their free game data in the headset app on first launch; Visual Pinball and ARMSX2 need separate user-supplied content.

The new paths and release selectors have automated tests. Hardware play for these nine projects has not been verified in this release.
