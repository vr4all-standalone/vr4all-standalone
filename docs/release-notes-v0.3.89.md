# VR4ALL v0.3.89 beta

- Added **Wario Land 4 VR** to the catalog with a creator-source link and Quest package detection. The creator has not published a Quest APK: build a personal ROM-specific APK on macOS using the creator's instructions, then select that APK in VR4ALL to install it. VR4ALL cannot build or auto-update this port yet.
- Renamed the library sort from **Latest release** to **Updated recently** and fixed it to use the most recent known creator release or discovery date. Ports with no known date stay at the end.

VR4ALL now lists 166 game cards, 7 emulator/runtime cards and 185 port choices. The Wario Land 4 card and sorting behavior have automated checks. Wario Land 4 has not been built or tested on a physical Quest through VR4ALL.
