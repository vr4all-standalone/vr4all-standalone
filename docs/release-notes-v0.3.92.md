# VR4ALL v0.3.92 beta

- Added **Newest** to the library sort menu. It shows all catalog cards in the order they were added to VR4ALL, newest first, including emulators.
- Removed the ten-card **New games** filter. Use **All games → Newest** to see recent additions without hiding the rest of the library.
- **Updated recently** still uses the creators' release dates; it remains separate from the new sort.
