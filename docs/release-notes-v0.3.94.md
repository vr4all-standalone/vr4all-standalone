# VR4ALL v0.3.94 beta

- Added **GTA III: Liberty City VR** from [kornacious/liberty-city-vr](https://github.com/kornacious/liberty-city-vr). Choose a complete owned GTA III PC folder, a ZIP/7z/RAR of it, or an original US Xbox disc ISO. VR4ALL checks required PC files, downloads the creator's SHA-256 verified Windows setup kit, then runs its manager to build and install a personal Quest APK and game data.
- Added the creator's GTA III artwork and included the game in Newest sorting. The catalog now has 169 game projects, 7 emulator tools and 188 port choices.
- The GTA III card asks for Android SDK license consent before starting. VR4ALL checks the finished Quest installation for the game's managed data variant. Its creator currently documents Quest 3 support; VR4ALL blocks Quest 3S and other models for this build.

COD4 is deferred. GTA III's full build and headset gameplay have not yet been tested by VR4ALL; the release includes input, routing and installer checks.
