# VR4ALL v0.3.56 beta

Adds **VtMB VR [re:Source]**, the early standalone Quest 3 port of *Vampire: The Masquerade – Bloodlines*. The card downloads the creator's Quest APK and Unofficial Patch release, then copies the patch with the `Vampire` folder from your owned PC copy into the folders the port expects. VR4ALL checks for the game archive and patched New Game script before marking the headset ready. Updates to the APK can reuse files already on the headset.

The profile was checked against the creator's v0.1.1 APK and patch ZIP. Their SHA-256 hashes matched GitHub's published digests, and the APK's actual Vulkan package name was verified from its manifest. The 14,941-file patch archive was inspected and extracted successfully. A full installation and game launch on a Quest have not yet been tested. The creator describes this as an early build with limited campaign testing and known gameplay issues. Quest 3 is the documented target; Quest 3S and Pro compatibility are unverified.

The catalog now has 124 game cards and 132 port choices.
