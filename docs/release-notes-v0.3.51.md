# VR4ALL v0.3.51 beta

Adds **Project Honeydew** and **Deus Ex Quest VR**, bringing the catalog to 116 game cards and 123 port choices.

Project Honeydew installs its current standalone Quest 3/3S APK directly from the creator's site. VR4ALL checks the site's published SHA-256, copies a player-owned Pikmin GameCube USA Rev 1 ISO or GCM to the headset, and checks the creator site for future APK updates. The game performs its own first-run disc import; VR4ALL cannot inspect that private import after the original disc image is removed.

Deus Ex is clearly marked **In development**. Its repository describes a limited source-built Quest 3 smoke test, not a published playable campaign APK. The card links to the creator for progress and does not offer an install action.

Both cards have local source-attributed artwork. Software checks and package inspection do not establish headset playability; no headset install or play test was performed for these additions.
