# VR4ALL v0.3.46 beta

**VR4ALL can now update itself.** After checking game ports, **Check updates** also checks VR4ALL's official GitHub releases. When a newer portable Windows EXE is available, VR4ALL asks before downloading it. On approval it shows download progress, verifies the release's SHA-256 digest, closes, replaces the portable file you launched, and reopens. It keeps your game choices and settings. If replacement fails, it restores the previous EXE and writes a local diagnostic. A running or queued game install prevents restart.

The automatic updater starts with this release. If you have v0.3.45 or older, download v0.3.46 once from GitHub; subsequent releases can be installed from inside VR4ALL. The development browser preview cannot replace itself.

This release keeps the **96-game catalog**, including CarnEvil VR. No game files are bundled.
