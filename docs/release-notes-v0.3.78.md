# VR4ALL v0.3.78 beta

- Added Silent Scope VR for Quest 3 and 3S. VR4ALL downloads the official Quest APK and accepts a folder, ZIP, 7z, or RAR containing your owned US Dreamcast V1.000 CUE and three BIN tracks.
- VR4ALL stages those four files on the headset. Open Silent Scope once and select them in its disc picker to complete the game's own validation and import.
- Headset scans recognize the installed app as ready after all four tracks have been imported. The card uses the original Dreamcast cover artwork.

The v0.3.77 DolphinXR install fix is included. Game files are never bundled with VR4ALL.
