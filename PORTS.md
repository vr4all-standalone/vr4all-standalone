# VR4All port inventory

The [143-entry Quest audit](docs/claude-143-quest-audit.md) checks the additional list title by title and distinguishes existing profiles, released native candidates, guided installs, and unrelated emulators or store games.

Checked on 2026-10-21–22. The app currently has **68 profiles**. The original 28 included 27 whose public GitHub release API returned a Quest APK matching the profile's filename rule. Seventeen more direct APK selectors were checked against author release assets; other profiles and Quest 3S play testing remain follow-up checks. Road Rash, UT99 Quest, Perfect Dark VR, Simpsons Hit & Run VR and Rave Racer VR ask for a local APK from the author source. Complex builds and multi-APK ports link to their official guides. A matching release verifies the download link, not that the game has been tested on this headset.

The app stores each exact repository and APK filename pattern in `src/catalog.js` when an official Quest APK name is known. **Check updates** asks GitHub again, while opening a card checks just that port. The latest *matching Quest APK* may differ from the repository's newest overall release if that release has no Quest APK. Manual profiles link to the author and require a locally selected APK. SourceVR is one profile for several games that share one package; game data must be imported per its author guide. AvP VR also needs a first launch before copying original PC game data into its app folder.
